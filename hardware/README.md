# Hardware — archivos de diseño

Aquí van los archivos fuente del modelo dividido para producción.

Los `.stl` y `.3mf` están excluidos por `.gitignore` (son pesados y binarios).
Versionar aquí únicamente:

- Notas de la división de piezas
- Medidas críticas y tolerancias
- Fotos de referencia del montaje
